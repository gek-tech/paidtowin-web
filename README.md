# paidtowin.de

Öffentliche Website von Paid to Win: Startseite, Impressum und Datenschutzerklärung
(Deutsch und Englisch). Wird über GitHub Pages ausgeliefert.

Vor dem Veröffentlichen alle Platzhalter in eckigen Klammern ausfüllen, z. B.
`[VOR- UND NACHNAME]`, `[STRASSE UND HAUSNUMMER]`, `[PLZ UND ORT]`, `[DATUM]`.
Suchen: in GitHub die Datei öffnen und nach `[` suchen.

Die App verlinkt auf `https://paidtowin.de/impressum/` und
`https://paidtowin.de/datenschutz/` (englisch: `/en/imprint/`, `/en/privacy/`).
